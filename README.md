## 01 / Currently building

### E-commerce Fraud Detection

`Autoencoder` → `Anomaly Score` → `LightGBM` → `Bayesian Optimization`

An end-to-end fraud detection pipeline built on the IEEE-CIS fraud dataset, combining unsupervised anomaly detection with supervised classification and automated hyperparameter tuning.

**Target:** PR-AUC ≥ 0.65

[View repository ↗](https://github.com/fahmiridho07/ecommerce_fraud_detection)
